# javascript-racingcar-precourse

### 기능 목록
#### 입력
- [x] 경주할 자동차 이름을 입력받는다.
- [x] 시도할 횟수 입력받는다.

#### 게임 로직
- [x] 자동차의 전진 여부를 판단한다. (무작위 값을 구해 4이상이면 전진하도록 판단)
- [x] 각 시도마다 자동차의 이동 결과를 갱신한다.
- [x] 시도 횟수만큼 자동차들을 경주시킨다.
- [ ] 최종 우승자를 판별한다.

#### 출력
- [ ] 자동차 하나의 결과를 출력한다.
- [ ] 각 차수의 실행 결과를 모두 출력한다.
- [ ] 최종 우승자를 출력한다.

#### 검증 (예외 처리)
- [ ] 자동차 이름 5자 초과할 경우 예외 처리
- [ ] 자동차 이름을 입력하지 않은 경우 예외 처리 
- [ ] 시도할 횟수가 음수일 경우 예외 처리
- [ ] 시도할 횟수가 정수가 아닐 경우 예외 처리
